Core Features (All Platforms)

  • USB Cleaning — Removes hidden dot-files and resource-fork “ghost” files so your instrument reads the drive cleanly.
  • Drive Prep — Build the correct folder structure for backups instantly.
  • Tree Management — 100 banks per backup (00–99), each with scenes A–F.
  • Dual-Tree View — Work with source and destination side-by-side.
  • Bi-Directional Moves — Drag banks/scenes either direction between trees.
  • Granular Control — Move an entire bank, a single scene, or a selected group of scenes anywhere.
  • Replace vs Swap modes:
    • Replace — Sends source → destination without altering the source.
    • Swap — Sends source → destination, then returns the destination’s original back to the source.
  • Undo — Instant rollback of the last operation.
  • Printing — Print the full tree or just a range (e.g., Banks 1–20) with crisp, high-contrast output.
  • Bulk Export — Convert batches of .rif → .sca without prompts.
  • Selective Restore — Extract whole archives or specific banks only.

How It Works (At a Glance)

  1. Connect USB → Use USB Cleaning to remove ghost & dot-files; build backup structure.
  2. Open Two Backups → Source on the left, Destination on the right.
  3. Choose Mode → Replace (leave source intact) or Swap (return destination original back to source).
  4. Drag & Drop → Entire banks, single scenes, or groups of scenes — in either direction.
  5. Undo if needed, then Print your range or Export scenes for sharing.
